# 🚀 Portfolio - React App

This project is a personal portfolio website built using [Create React App](https://github.com/facebook/create-react-app).

## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Novah974-8/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

Before running the project, install all necessary packages:

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

---

## 📦 Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
It reloads automatically when you make changes.

### `npm run build`

Builds the app for production in the `build` folder.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run eject`

**Warning:** This is a one-way operation. Once you `eject`, you can't go back!
